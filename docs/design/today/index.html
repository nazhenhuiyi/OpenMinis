原型里体现的规则

  • 最新的在最下面，输入框在底部；往上滑是昨天
  • 只有 DCIM/Camera/ 和 DCIM/Minis/ 里的照片会出现，微信存图和截图不出现
  • 满足任一条件就开始新的照片组：间隔超过阈值、中间有碎碎念、整组跨度超过 3 小时、跨天
  • 📷 在输入框里面；在「今日」里拍的照片先放进输入框；发送时有文字就挂在这条碎碎念下面，没有文字就放回时间线参与聚合
  • 发送立刻上屏，位置在后台补上（"定位中…"）
  • 照片组只显示缩略图和地名，不显示「N 张」
  • 照片组没有删除选项，要删去相册删；碎碎念引用的照片被删后显示占位
  • 「问问 Minis」会新建对话并带上引用，不会自动发送
