App 事件Rive 输入形象表现

        
无任务state=0 idle呼吸、眨眼、眼睛跟随手指；25 秒无交互 → 睡觉

        
语音输入中state=1 listening + volume耳朵竖起、身体前倾、两侧声波随音量变化

        
已发送、等待模型state=2 thinking眼睛往上看、天线星星旋转发光、思考泡泡

        
调用工具（toolIcon）state=3 working + tool举起对应道具：地球 / 终端 / 文件 / 放大镜，专注眉

        
TTS 朗读中（isAudioPlaying）state=4 speaking + talking + volume嘴型跟随音量开合，气泡显示字幕

        
任务完成（allCompleted）state=5 done跳起、举双手、撒星星，约 2.6 秒后自动回到 idle

        
请求出错state=6 error> < 眼、担心眉、摇头、问号

        
长时间空闲state=7 sleeping闭眼、耳朵耷拉、慢呼吸、Zz；点一下会惊醒

        
用户点击 / 抚摸tap / pet（Trigger）惊讶后开心、冒爱心、耳朵抖动，亲密度增加
