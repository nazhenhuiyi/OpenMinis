# 碎碎念标注规范 v1

设计见 `docs/design/today/MURMUR_MODEL.md`。生成数据、打标签、人工抽查都以这份为准。

输出一行：`意图|情绪|方面|提及|高光`

## 意图：记录 / 待办 / 查询

- **待办**：写的人自己接下来要去做的具体的事。信号是"明天、今晚、待会儿、下周、得、要、记得、准备、别忘了"，或者东西用完了要补（"洗发水没了"）。只要整段里有一句是待办，就是待办
- **查询**：写的人真的想知道答案的具体问题。比如认东西（"这是什么花"）、问做法（"怎么去水垢"）、问原因（"为什么一吃面就胀气"）、问事实（"这两种药能一起吃吗"）、直接请人帮忙查或推荐
- **记录**：其余都是。包括：
  - 已经做完的事（"做了""买了""终于交了"）
  - 愿望和模糊的打算（"希望……""想去……""有机会试试""以后要早点睡"）
  - 反问、感慨、思考人生、社会、AI（"如何更有活人感？""会不会有一天……"）
  - 观点和评价
- 待办和查询同时出现时，选更具体、更紧急的那个
- 拿不准的时候，在待办/查询和记录之间**偏向待办/查询**（后面有云端确认）

## 情绪（单选）

开心 · 满足 · 感动 · 期待 · 平静 · 好奇 · 疲惫 · 低落 · 焦虑 · 烦躁 · 生气 · 难受

- 开心：明显的高兴、兴奋（"wow，开心""大成功"）
- 满足：舒服、惬意、小小的成就感、觉得不错（"还蛮好吃""提高了幸福度"）
- 感动：被作品、人、景打动（"写的太美了""感动人心"）
- 期待：盼着某件事（"有点期待明天吃什么"）
- 平静：没有明显情绪的记录、讲道理、发表观点
- 好奇：真的想知道（"这是什么花呀"）
- 疲惫：累、困、乏
- 低落：难过、虚无、挫败、失落、怀念里带伤感
- 焦虑：担心、紧张、对未来不安（裁员、失业、考试）
- 烦躁：被小事惹得不耐烦、抱怨（太热、太挤、外卖迟到）
- 生气：明显的愤怒、骂人
- 难受：身体不舒服（头痛、牙痛、吃撑、卡药）
- **满足和平静的分界**：写的人对**自己的经历**给出了正面评价（不错、好吃、舒服、值得、香、真好看、提高了幸福度），算满足；只是描述发生了什么、看到了什么，没有评价，算平静。讲道理时用到"幸福""美好"这类词，评价的不是自己的经历，仍然算平静
- **开心和满足的分界**：好消息、做成了、兴奋、感叹（"太……了"、"！"、"哈哈"），算开心；语气平稳的舒服、惬意，算满足
- 只写做了什么、吃了什么、去了哪里，一句评价都没有（"早餐吃了煎饼果子"、"跳绳一千个"），算平静
- **低落和平静的分界**：观点里带悲观，但没写自己的感受（"城市越大越孤独"），算平静；写了自己的失落、无力、虚无、挫败，算低落
- 混合情绪取写得最重、或者最后落脚的那一种
- 诗句、引文：看写的人对它的反应（"写的太美了"→感动），不看诗本身的情绪

## 方面（1～2 个，最主要的在前，用 `,` 分隔）

吃喝 · 身体 · 运动 · 工作 · 学习阅读 · 影音娱乐 · 家人 · 朋友社交 · 伴侣 · 孩子 · 宠物 · 自然天气 · 出行 · 居家 · 钱 · 创作爱好 · 想法

- 想法：对人生、社会、AI、创作的观点和思考，没有具体生活事件
- 身体：病痛、睡眠、体重、吃药
- 自然天气：天气、季节、花草、鸟、天空
- 出行：旅行、通勤、交通
- 居家：家务、家里的物品
- 创作爱好：画画、写作、手账、做自己的项目

## 提及（0～5 个，`类型:原文`，用 `;` 分隔，没有写 `无`）

| 类型 | 收 | 不收 |
|---|---|---|
| 吃喝 | 具体的菜、食物、饮料：宫保虾球、明前茶、饺子 | 泛指：饭、菜、外卖、美食 |
| 书影 | 书名、剧名、电影、作者：《朝花夕拾》、鲁迅、昨日的美食 | 泛指：书、电影 |
| 音乐 | 歌名、歌手、乐队：曾轶可、阳台民谣 | 泛指：歌 |
| 人 | 生活里的具体的人：妈、二姨、媳妇、小王、奎 | 泛指：大家、很多人、别人、同事们 |
| 地点 | 有名字的地方，以及图书馆、健身房、医院、公园、超市这类场所 | 家、公司、外面 |
| 症状 | 偏头痛、牙痛、头晕、感冒 | 泛泛的"不舒服" |
| 药 | 布洛芬、止痛药 | |
| 运动 | 游泳、跑步、健身、哈克深蹲 | |
| 数量 | 运动量和身体数据：800米、34分钟、68.5公斤 | 其他数字 |
| 花销 | 金额：一百二、200美元 | |
| 植物 | 绣球花、三角梅 | 泛指：花、树 |
| 动物 | 白鹭、柯基、猫 | 泛指：鸟、虫子 |

- **原文必须在碎碎念里一字不差地出现**（书名号可有可无，以原文为准）
- 按出现顺序；同一个东西只写一次；超过 5 个只留最有回看价值的
- 写做菜过程时，只记菜名（咖喱、寿喜锅），不列配料（洋葱、香菇、生抽）
- 诗人、作家、歌手、画家记在书影或音乐下，不记在"人"下面

## 高光：是 / 否

第一次、做成了、明显进步、难得的时刻（婚礼、旅行、演唱会）。日常的好吃好看不算。从严。
